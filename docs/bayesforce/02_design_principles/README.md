## 🎨 Quick Reference

| Token | Name | Value | Purpose |
| :--- | :--- | :--- | :--- |
| `--color-brand` | **Cobalt Blue** | `#013EFA` | Signal color: Logo, primary CTAs, links, active states |
| `--color-obsidian` | **Obsidian Black** | `#11151B` | Authority: Hero background, dark sections, footers |
| `--color-surface` | **White / Surface** | `#FFFFFF` | Clarity: Light backgrounds, clean readability |
| `--font-display` | **Outfit** | `"Outfit", sans-serif` | Display, hero headlines, section titles, buttons |
| `--font-body` | **Inter** | `"Inter", sans-serif` | Body text, UI, tables, metadata |
