## 🎨 Quick Token Reference

| Token | Name | Value | Purpose |
| :--- | :--- | :--- | :--- |
| `--color-brand` | **Cobalt Blue** | `#013EFA` | Signal color: Logo, primary CTAs, links, active states |

| `--font-body` | **Inter** | `"Inter", sans-serif` | Body text, UI, tables, metadata |
