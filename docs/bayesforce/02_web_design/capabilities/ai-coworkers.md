## 3. Section Blueprints & Copy Details

### Section 1: Hero
- **Headline (H1):** *Coworkers that execute, not just advise.*
- **Subcopy:** Most AI tools generate text and leave the execution to humans. BayesForce builds AI coworkers with tool-calling capabilities that inspect systems, cross-reference data, draft records, and perform actions directly within your software stack.
- **Visual:** Side-by-side terminal simulation showing an inbound request in Slack triggering an automated lookup in Salesforce, document parsing in NetSuite, and posting an approval card back to the human reviewer.

### Section 2: Core Engineering Capabilities
- **Multi-System Tool Calling:** Secure, authenticated API invocation across internal microservices and third-party SaaS platforms with strict parameter schemas.
- **Stateful Execution & Plan Memory:** Maintains transaction context across asynchronous events, webhooks, and delayed human approvals.
- **Deterministic Action Boundaries:** Separates read operations (autonomous) from write/update operations (governed by earned autonomy rules).
- **Human Review Modals:** Lightweight Slack/Teams interactive action cards for one-click confirmation or remediation.
